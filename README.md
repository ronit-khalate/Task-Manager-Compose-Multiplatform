# Task Manager Compose for Multiplatform

## Project Structure
- **app**: Contains the main application code.
- **shared**: Includes shared logic across platforms.
- **build.gradle**: Gradle build configuration.

## Setup Instructions
1. Clone the repository using `git clone https://github.com/ronit-khalate/Task-Manager-Compose-Multiplatform.git`
2. Navigate to the project directory: `cd Task-Manager-Compose-Multiplatform`
3. Open the project in your preferred IDE (e.g., Android Studio).
4. Sync the Gradle files to ensure all dependencies are resolved.
5. Run the application on your desired emulator or device.
